Website Site Plan

Heritage Africa Explorer

Site Name

Heritage Africa Explorer

This name was chosen because the website focuses on exploring African cultures, historical landmarks, and travel destinations. It reflects discovery, learning, and appreciation of African heritage.

Optional domain: heritageafricaexplorer.com

Site Purpose

The purpose of this website is to provide users with educational and travel-related information about African countries, cultural heritage sites, and tourist attractions.

  • Showcase African historical landmarks and cultural facts
  • Provide travel guides and recommendations
  • Allow users to explore countries through images and summaries

Scenarios

  • What are the most famous cultural heritage sites in Africa?
  • Which African countries are best for first-time tourists?
  • What historical events shaped modern African nations?

Color Schema

The selected colors for this website are:

#1b4332 (Primary - Headings, Header, Navigation)
#f4a261 (Accent - Borders, Highlights, Buttons)

The primary color will be used for headings and structure elements, while the secondary color will highlight important UI elements like buttons and section borders.

Typography

Font Family: Poppins (Google Fonts)

  • Headings: Poppins Bold
  • Body Text: Poppins Regular
  • Accents: Poppins Medium

Poppins was chosen because it is clean, modern, and highly readable on both mobile and desktop screens.
